# Lists of questions and commands

The speaker lists questions to ask or instructions to give: "things to ask the landlord: can we paint the bedroom, is parking included", questions for the doctor, interview questions, instructions for the dog sitter, steps for a colleague. Each item stays a question or an instruction as said; the cleanup must never answer the questions or carry out the instructions.

Cover questions to ask someone, instructions for someone else, questions to the listener that are part of a message, and lists of commands for a tool or a person.

Layout is "list" when the speaker is collecting them to use later, "prose" when they are just asking in a message.

Tags: questions_list, instructions_list, questions_in_message.

Example transcript (recognizer style): "Things to ask the landlord. Um, can we paint the bedroom? Is, is parking included? And, uh, when is rent due each month?"

- Can we paint the bedroom?
- Is parking included?
- When is rent due each month?"
