# Spelled-out symbols and spoken layout commands

Technical and everyday dictation where the speaker says symbols and layout out loud, and the cleanup writes the real thing.

Cover:
- command-line flags and code symbols: "dash dash help", "dash v", "pipe", "greater than", "open paren", "close curly brace", "equals equals", "underscore", "dot py", "slash usr slash local", "tilde", "at sign", "hash", "backslash";
- spoken punctuation: "comma", "period", "question mark", "colon", "open quote", "close quote", "dash", "exclamation point";
- spoken layout commands: "new line", "new paragraph", "bullet point", "next bullet", "number one... number two";
- email addresses and URLs spoken out ("jane dot doe at gmail dot com", "github dot com slash...");
- a mix of plain words and symbols, in messages to colleagues, notes, commit messages, emails.

Keep code, paths, flags and names exactly as dictated once the symbols are written. Layout is "list" when the speaker dictates bullets or numbered items, otherwise "prose".

Tags: cli_flags, code_symbols, spoken_punctuation, layout_command, spoken_email_or_url.

Example transcript (recognizer style): "Okay so run um pip install dash dash upgrade pip, then cd into the tilde slash projects slash API folder. New paragraph. If that fails uh send me the log."
Cleaned: "Run pip install --upgrade pip, then cd into the ~/projects/API folder.

If that fails, send me the log."
